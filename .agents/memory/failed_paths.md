# 🪦 Failed Paths & Dead Ends (避坑索引)

- [PITFALL-01] 混淆算法内存基准与端到端 Pipeline 延时：在评估 20 区空间投射和时序投票时，若未显式剥离视频解帧、YOLO 检测与 SAM2 分割开销直接宣称全链路 1~3ms，会导致工程落地预期严重失真。后续所有性能测试必须显式前缀 "Algorithm-only Benchmark" 并标注适用边界。
- [PITFALL-02] 长视频跳帧步长失控导致追踪轨迹撕裂与目标 ID 跳变：在快攻长传或镜头高速横摇场景下，若采用固定大步长（如 stride >= 8）进行帧过滤，会导致卡尔曼滤波器（Kalman Filter）状态外推发散，造成严重的跟踪断链与 ID 频繁切换。解决方案：必须使用运动量感知的自适应动态步长（`AdaptiveTemporalStrideController`），在剧烈运动时限制步长至 2 帧，仅在死球/阵地战时平滑放大至 6 帧。
- [PITFALL-03] 阵型质心单纯正负号判定守门员方向失真：在全队大幅度压上或高位控球场景下，全队平均 X 坐标常呈现大幅正值（如 +14.2m），若单纯使用均值符号判定防守球门方向，会将右侧底线球门误判为己方球门，进而错误地将深入对方腹地 50m 的边锋/前锋当成守门员剔除，导致凸包面积从 2000m² 骤降为 1800m²。解决方案：改用边界极大空隙差（Left Gap vs Right Gap 空间孤立度分析）结合显式进攻朝向解耦，准确锁定后场拖后守门员。
